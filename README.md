# 名实 · Míngshí

## 项目名

名实（Míngshí）——取意先秦名家"名实之辩"。

## 简介

先秦名家考辨"名与实"的关系；本项目考辨译名——把被音译吞掉的语义，用意译还回来。名不正则言不顺，译不正则义不明。按医学、数学、物理、化学、生物学、工程与通用等门类，收录纯音译与编号化命名造成的"丢义"词条，逐一给出理想意译；另附意译典范与音译兼意译（巧译）作为对照。

汉语翻译史上，最早一批文化工作者（徐光启、李善兰、徐寿、严复、钱学森……）以**意译**为主：用汉语自己的构词能力传达概念——几何、函数、微积分、氢氧氮氯、激光、导弹、电话、计算机，无一不是"读其名而知其义"。

后来的翻译者越来越懒：遇到新概念，不再琢磨它**是什么**，而是按原语发音直接搬过来——基孔肯雅热、特斯拉线圈、甲肝乙肝、布尔代数、阿司匹林……汉语从"表意文字"退化成了"注音符号"。

这个仓库把"懒译"按学科归类，逐一列出理想意译，供讨论与纪念。

## 三类译法

判断一个音译词好不好，标准只有一个：**字面是否承载语义**。

| 译法 | 标准 | 例子 |
|---|---|---|
| 纯意译 | 完全用汉语构词表达概念 | 激光（激发的光线）、青霉素、电动机、几何 |
| 音译兼意译（巧译） | 既取原音，所选汉字又自带贴切含义 | 拓扑（拓=延展、扑=贴近）、基因、幽默、可口可乐 |
| 纯音译（懒译） | 只取原音，字面毫无含义 | 基孔肯雅热、特斯拉线圈、布尔代数、盘尼西林 |

正如"火 + 山 = 火山"，汉字组合本身就是意义的载体。**音译不必然是懒译**——能挑出含义贴切的字，就是巧译；只剩下注音，才是本项目要批评的对象。判断标准与时代无关：新造的人名综合征、体征（麦氏点、巴氏征、克罗恩病……）只要字面不承载语义，同样是懒译。**编号化命名同理**：甲肝乙肝的"甲乙丙"只是分型序号（1947 年 MacCallum 分型的天干对译），同样不承载任何语义。各学科表收录**纯音译（懒译）**，另附 [07 意译典范](07-意译典范.md) 与 [08 音译兼意译](08-音译兼意译.md) 作为对照。

## 表格字段

| 原始中文 | 原始来源语言 | 正确译文 | 备注 |
|---|---|---|---|

- **原始中文**：现行通用（或曾经流行）的音译名
- **原始来源语言**：音译所据的语言，含人名 / 地名 / 商标等来源说明
- **正确译文**：理想意译名（部分为历史真实译名，部分为建议译法）
- **备注**：一句话二次解释，说明词源或为何意译更佳

> 说明：多数音译名已约定俗成、难以改回，本表无意推翻现行规范，重在展示"意译"的可行性与美感。存在争议的词条已在备注中说明。
